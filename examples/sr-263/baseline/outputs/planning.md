# Architecture survey

ServiceFlow needs a workflow engine before it can reopen a request. Option A adds a route. Option B adds a notes table. Option C replaces resolve, approve, and reopen with one engine. The plan includes mail, Slack, a risk register, and a rollback.

The test file and the release notes are drafted below the survey. Pending approval is treated as eligible for reopen so requests do not get stuck. Priority is raised to High on the way back to Open.
