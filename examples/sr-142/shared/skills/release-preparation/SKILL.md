# Release preparation

Write a short change summary and release notes for the feature that just passed its tests.

Include the user-visible behaviour, the default for existing data, and the test command that passed. Leave out the architecture tour and a regenerated test plan.

State that release in this lab is local: the CI workflow has been run, and nothing is deployed to production.
