# SR-142: Add request priority management

As a service team member, I want to assign a priority to a request so that urgent work can be identified and handled first.

## Acceptance criteria

- Requests support Low, Medium, and High priorities.
- Priority is selectable when creating or editing a request.
- The API validates and persists the priority.
- The dashboard can filter requests by priority.
- Existing requests default to Medium.
- Automated tests cover the new behaviour.
- The feature passes CI checks and is ready for release.

## Complication introduced during implementation

The priority is also shown as a coloured badge on the request dashboard, using the existing design system. Low is neutral, Medium is attention, High is urgent. Do not invent a new colour scale.
