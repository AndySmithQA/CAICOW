# Architecture survey

ServiceFlow is a request tracker. The plan below restates the lifecycle, the status model, every route, and the dashboard before it reaches priority.

The request module should be considered for a split. Option A adds a column. Option B extracts a priority service. Option C rewrites the request aggregate. The programme plan includes documentation and training milestones.

Priority values can be decided after the survey. The badge can use a new palette. Tests can be a new suite generated with the implementation.
