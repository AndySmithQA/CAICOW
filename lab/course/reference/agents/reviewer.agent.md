# Reviewer agent

Review the diff for SR-263. Check the status rule, the caller, the reason length, the requester audience, the unchanged priority, the audit row, and the tests that cover those cases.

Confirm the resolve tests and the comment tests are still in the run. Call out a missing test. Do not request a new suite, and do not restate the repository before the defects.
